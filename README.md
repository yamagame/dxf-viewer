# DXF Viewer

DXFファイルをブラウザ上で読み込んで表示するシンプルなWebアプリです。
ツールバーを上部に配置し、図面表示領域はウインドウ全体に広がります。

## 使い方

1. このディレクトリでローカルサーバーを起動
2. ブラウザで `http://localhost:8000` を開く
3. `DXF` ファイルを選択

```bash
python3 -m http.server 8000
```

## ビュー操作

- 全体表示: 図面全体が収まる表示に戻します
- 拡大 +: 表示領域を拡大します
- 縮小 -: 表示領域を縮小します
- Shift + 左ドラッグ、またはマウス中央ボタンのドラッグ移動: 表示位置を移動できます
- ショートカットキー:
  - `+` / `=`: 拡大
  - `-`: 縮小
- マウスホイール: ホイール上回転で拡大、下回転で縮小
- 距離測定: 頂点を2つクリックすると距離を表示します（LINE / POLYLINE の頂点）
- 距離測定結果には全体距離に加えて `ΔX` / `ΔY` も表示します
- 頂点ホバー表示: カーソル直下の頂点を青色でハイライト表示します
- 交点選択: LINE / POLYLINE の線分同士の交点も頂点として選択できます
- レイヤー表示切替: 右上のフローティングウインドウで各レイヤーを表示/非表示にできます
- エッジ選択: エッジをクリックすると選択され、そのエッジが属するレイヤー名を表示します

## 対応エンティティ

- LINE
- LWPOLYLINE / POLYLINE
- CIRCLE
- ARC
