# DXF Viewer

DXF ファイルと JWW（JW_cad 形式）ファイルをブラウザ上で読み込んで表示するシンプルなWebアプリです。
ツールバーを上部に配置し、図面表示領域はウインドウ全体に広がります。

## 使い方

1. 依存関係をインストール
2. 開発サーバーを起動
3. ブラウザで表示されたURL（通常 `http://localhost:5173`）を開く
4. `DXF` または `JWW` ファイルを選択

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
npm run preview
```

ユニットテスト実行:

```bash
npm test
```

## ビュー操作

- 全体表示: 図面全体が収まる表示に戻します
- 拡大 +: 表示領域を拡大します
- 縮小 -: 表示領域を縮小します
- Shift + 左ドラッグ、またはマウス中央ボタンのドラッグ移動: 表示位置を移動できます
- ショートカットキー:
  - `+` / `=`: 拡大
  - `-`: 縮小
- マウスホイール: ホイール上回転で拡大、下回転で縮小
- 距離測定: 頂点を2つクリックすると距離を表示します（DXF の LINE / POLYLINE、JWW の線の頂点）
- 距離測定結果には全体距離に加えて `ΔX` / `ΔY` も表示します
- Option（Alt）+ 頂点/交点クリック: 旧2点目を新1点目に繰り上げた後、新2点目を設定します
- 頂点ホバー表示: カーソル直下の頂点を青色でハイライト表示します
- 交点選択: 線分同士の交点も頂点として選択できます
- レイヤー表示切替: 右上のフローティングウインドウで各レイヤーを表示/非表示にできます
- エッジ選択: エッジをクリックすると選択され、そのエッジが属するレイヤー名を表示します

## 対応形式

### DXF

対応エンティティは次のとおりです。

- LINE
- LWPOLYLINE / POLYLINE
- CIRCLE
- ARC

### JWW（JW_cad 形式）

描画する要素は次のとおりです。

- 線（距離測定とエッジ選択の対象になります）
- 真円 / 円弧（DXF の CIRCLE / ARC と同じく、描画のみで距離測定とエッジ選択の対象外です）

レイヤーは、レイヤグループとレイヤを連結した1つの名前（例: `0-5 (寸法)`）としてレイヤー一覧に並びます。
ファイル内で非表示として保存されていたレイヤーは、読み込み直後は非表示の状態でレイヤー一覧に並び、チェックを入れると表示に切り替わります。

#### JWW で対応していないこと

- 文字・寸法・ソリッド（塗りつぶし）・点・ブロック（図形）は展開せず、描画しません
- 楕円および扁平率を持つ円弧は描画しません（残りの図形はそのまま描画します）
- レイヤグループの縮尺による実寸換算は行わず、ファイル内の座標値をそのままモデル座標として扱います
- 線種・線色・線幅は再現しません
- 編集・保存・書き出し、および DXF ⇔ JWW の相互変換には対応しません
