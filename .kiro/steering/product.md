# プロダクト概要

ブラウザ上で DXF（図面交換）ファイルを読み込み、Canvas に描画して閲覧・計測できるシングルページの Web アプリケーション。サーバーを持たず、ファイル選択からパース・描画・計測までをすべてクライアント側で完結させる。CAD ソフトを持たない利用者が、図面の内容確認と簡易的な寸法確認を行うことを想定している。

## コア機能

- **DXF 読み込みと描画**: ローカルの DXF ファイルを選択し、対応エンティティを Canvas 2D に描画する
- **ビュー操作**: 全体表示（フィット）、拡大/縮小（ボタン・キー・ホイール）、パン（Shift + ドラッグ / 中ボタンドラッグ）
- **距離測定**: 2 頂点を選択して距離と ΔX / ΔY を表示する。頂点には線分同士の交点も含まれる
- **要素選択**: エッジをクリックして選択し、所属レイヤー名を表示する。カーソル直下の頂点はホバーでハイライトする
- **レイヤー表示切替**: 図面に含まれるレイヤーごとに表示/非表示を切り替える

対応エンティティは LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC。

## 想定ユースケース

- 受け取った DXF の内容を、CAD 環境を用意せずその場で確認したい
- 図面上の 2 点間の距離や XY 方向の差分を素早く測りたい
- レイヤー構成を確認し、特定レイヤーだけを表示して読み解きたい

## 価値提案

- **インストール不要・オフライン完結**: ファイルはブラウザ外へ送出されず、バックエンドを必要としない
- **測定に振り切った操作系**: 頂点スナップと交点スナップを標準で備え、クリックだけで寸法が得られる
- **軽量な構成**: 依存は DXF パーサのみで、描画は Canvas 2D に限定している

## UI 言語

画面表示・ステータスメッセージはすべて日本語。メッセージ文言はロジック層（各 Manager クラス）が返却する文字列に含まれるため、文言変更はクラス側で行う。
